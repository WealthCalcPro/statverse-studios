# StatVerse Studios Website

Production-ready static starter for StatVerse Studios based on the supplied business brief.

## Structure
- `index.html` — main one-page agency site
- `styles.css` — responsive visual system and animations
- `script.js` — mobile nav, reveal animations, email-client enquiry flow
- `legal/` — Privacy Policy, Disclaimer, Terms starter pages
- `assets/favicon.svg` — lightweight brand favicon

## Deploy to Vercel
This version is intentionally framework-free. Drag the folder into a Git repository and import it into Vercel, or use Vercel's static deployment flow.

## Important before launch
1. Put the existing StatVerse Studios transparent logo at `assets/logo.png` and replace the text brand in `index.html` if desired.
2. Create the final business email and update `BUSINESS_EMAIL` in `script.js`, plus the visible email strings in `index.html` and legal pages.
3. Replace `og:url` with the final live site URL after deployment.
4. Review the legal templates against your real practices; they are not legal advice.
5. The contact form currently opens the visitor's email client with a prepared message. It does not store submissions in a database.
6. Add a real WhatsApp number only after one exists.

## Honesty rules built into the copy
- Demo showcase is labeled as demo/example work.
- No fake customers, testimonials, sales counts or visitor metrics are used.
- Pricing language notes potential extra costs for domains, paid services and advanced functionality.
